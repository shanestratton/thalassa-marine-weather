# Build 142 lossless authored UI data representation

The build keeps the existing four UI data pools, the existing SVG path pool, and the original decoder. No application component, rendered text, path geometry, CSS assignment, native identity, quota, or bundle ceiling changes.

The build-only candidate packer tries the original sorted word dictionary, a deterministic frequency-width dictionary, and whole strings as dictionary words. Every option uses the same bounded `[words, rows]` tuple and original checksum decoder: 128,000 raw bytes, 64,000 encoded characters, 4,096 entries, 8,192 words, 4,096 characters per word, 16,384 characters per row and 256,000 restored characters. UI tables retain their tighter 240,000-character per-table and four-table aggregate checks. The original class collector and class packer are unchanged.

The original UI literal grammar is shared by the two source collectors. All 8,531 originally selected UI and SVG values remain represented. Additional plain literal JSX `path d` values can use the existing SVG pool only when every cooked source occurrence is explained by a plain, unique-attribute path. The original 80 SVG values remain. No path normalization occurs.

Twenty-six exact source hashes admit 124 authored CSS literal/quasi occurrences (117 unique values) in `element.style.cssText`, an actual lexical `const document.createElement('style')` variable's `textContent`, or imported React JSX `style` children. Only literal data and cooked literal template quasis enter the existing UI pools. Original dynamic expressions, coercions and assignment ownership stay in place. Tagged templates, ambiguous/shadowed style variables, bootstrap readers and ChatPage are excluded. `.ts` CSS owners never receive the general UI literal walker, so unrelated protocol/error text stays verbatim. A changed CSS owner refuses until its inventory is reviewed again.

Repeated build-only source reads use a cache of at most two exact SHA-256 cohorts, keyed by ordered file names and their complete source bytes. File times are never authoritative, and every caller receives a separate Map. The test changes a same-length file while restoring its original timestamps to prove invalidation; no application data or runtime position is cached here.

Three ordinary frozen SVG attribute objects supplement the original eight variants: the consecutive round-cap/join pair, `viewBox` then current-color fill, and none fill then `viewBox`. All properties must be plain and unique; exact consecutive positions, primitive values, dynamic effects, children, IDs and handlers are retained. No extra compressed pool or runtime codec is introduced.

`UiDataPacking142.test.ts` checks the actual old/current cohorts, original decoder identity and refusals, all canonical CSS fragments and source-token reversal, real minified CSS coercion order, all three SVG runs, and worker closure exclusion. Existing packing, icon, inert-reader and worker-fence tests are retained unchanged. The production plugin disables transformation and virtual table resolution in worker builds; the existing independent worker fence remains authoritative.

The source-only estimate is 73,141 bytes saved before unknown graph/import effects, or 69,141 bytes with a 4,000-byte reserve. That is not a configured build result. The prior SDK-only configured result still exceeds the unchanged JavaScript limit by 71,936 bytes; the combined exact build is required before budget acceptance. A separate className-only source expansion measured only about 3,133 extra bytes and was not implemented.
