# Optical lightning supplement source

Satellite flashes are a separate lazy, defaultOFF Sky layer. Violet hollow
diamonds show original optical flash centroids; they do not impersonate the
licensed network's pulses,CG/IC type, polarity or20NM watch. No source from
this module is imported by the licensed watch or push sender. The existing
Credits rollup contains original UTC, provider/platform, limited coverage,
overlap/capping and gap warnings. No map strip or automatic camera move is added.

Primary sources are the [NOAA GLM description](https://www.nesdis.noaa.gov/our-satellites/currently-flying/goes-east-west/geostationary-lightning-mapper-glm?page=0),
[NOAA NODD delivery/terms](https://registry.opendata.aws/noaa-goes/),
[original LCFA metadata](https://www.ncei.noaa.gov/access/metadata/landing-page/bin/iso?id=gov.noaa.ncdc%3AC01527%3Bview%3Diso),
[EUMETSAT flash catalogue](https://api.eumetsat.int/data/browse/collections/EO%3AEUM%3ADAT%3A0691?format=html),
[LI format appendices](https://user.eumetsat.int/s3/eup-strapi-media/MTG_LI_Level_2_data_guide_Appendices_5967c5a472.pdf)
and [2025 EUMETSAT policy](<https://www-cdn.eumetsat.int/files/2025-02/45173%20-%20Data_Policy(1442019%20V1).pdf>).
NOAA's open-use terms and LI Core/NoConditions policy provide reuse paths;
neither proves configured transport, current native format or source admission.

The actual client reads only the fixed owned R2 prefix after an explicit
toggle and foreground/network admission. Importing or leaving itOFF makes no
data request. It verifies the immutable index and each requested tile's original
SHA/byte count, strict product/QC/provenance, original observation windows and
expiry. A viewport is bounded to9five-degree tiles and600 actual centroids;
768KiB cumulative bytes and2unfinished native requests bound each session.
Aborted requests retain their slots until the real promises settle.

Each observation expires after5minutes, independent of receipt time. The
immutable index lasts at most60seconds; it does not refresh itself. Account,
foreground, offline, Satellite Mode, rollback, expiry and owner retirement
permanently close the snapshot; A/B/A does not revive it. Plan and Hide all
pause/remove the owned display. Missing coverage, unavailable public admission
and empty qualified sources leave explicitly unknown gaps. No Australian
coverage is assumed. Multiple instruments can show one physical flash twice.

The server source prepares original-aware private packets and strict root
admission. Current native original extraction, isolated native proof, registered
MTG original transport, owned publication/inventory and any scheduler remain
held. See the separate weather repository `ops/OPTICAL-LIGHTNING142.md` for
the precise bounded original/native/publication proposal. No provider fetch,
subscription, credential request, purchase, public write, push or deployment
was performed by this packet. This is source groundwork and client acceptance,
not a claim that a live optical feed is available.

Final source proof:24 new cases plus8 existing ASCAT/menu/licensed-layer
regressions pass across5 suites. They include exact cross-language sealed
fixture hashes, original-time/product/QC refusal, unsupported group/network
relabelling, owner A/B/A, source/network/expiry retirement, zero default I/O,
superseded views and native fetch slots staying reserved after abort.
Scoped lint and formatting pass. Four final Chrome/WebKit phone cases at
300/375px,130% text and667px height pass with unchanged map/document bounds,
44px controls, Hide all, no extra requests and pinned Close after bottom scroll.
The ordinary keyboard browser job includes the new spec. Screenshots were
inspected; the fixture is explicitly fictional and its map host is synthetic,
so it does not prove physical map rendering, provider observations or login.

The first phone run's duplicate status/detail text locator failed and remains
preserved. Scoping the locator to the actual named source region retained all
wording and geometry checks. The final run follows additional conservative
aggregate/source-expiry/ID validation checks. No whole-app compiler or
configured budget build was run here; added production bytes must be measured
in root's final composition. Native original extraction, actual product
acquisition, owned publishing and service admission remain pending the
separate concrete review proposal rather than being called complete.
