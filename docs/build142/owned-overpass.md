# Owned worldwide OSM reference boundary (142-07)

This packet prepares the owned Overpass query path and retires app, Edge and Pi public-mirror calls. It does **not** install or admit a global database, open ingress, deploy an Edge, start a download/timer, or prove worldwide availability. Missing admission returns unavailable; it never manufactures an empty inventory. The separate facilities extract is partial and cannot qualify this database.

The actual app paths are SeamarkService, CruisingReferenceService (including named bays/towns), coastline shelter reference, cloud/Pi route overlays and pilotage/seamarks. The existing Today plan asks at most four bounded name cells where the atlas has no places; missing or sentinel-limited cells remain partial. Existing land/water selection, route geometry and the no-coastline/undamped-wave fallback remain unchanged. Main Glass best-local-model selection is a separate remaining integration; this packet does not label global coarse data as AROME.

## Prepared boundary

App -> fixed `owned-overpass` Edge -> separately credentialed fixed owned gateway -> loopback interpreter. Pi uses its existing **public** Supabase credential and existing outbound DNS/redirect/private-host policy, never the private gateway credential. Web and native use the same Edge. No caller supplies an endpoint or raw QL across the public Edge; a pure mirrored contract accepts seven exact existing query families and bounded boxes. Names/references are exact one-degree cells; antimeridian splitting stays upstream. Unknown, mixed-box, global or modified QL cannot be adapted.

The gateway is prepared for loopback `127.0.0.1:8092`, with a separately reviewed TLS ingress required before use. It has one active query lease, 4 KiB input, 20 MB response, 20-second complete-body deadline, fixed interpreter origin, 128 MiB per-query QL maximum and 20-second interpreter timeout. An ignored-abort operation keeps that lease occupied until its original work retires, so repeated callers cannot amplify orphan requests. Actual dispatcher one-slot enforcement and its total resource cap must be demonstrated by a native installation proof; the JavaScript lease is not proof of interpreter process limits.

The readiness file is a bounded, non-symlink, non-group/world-writable regular file. It requires an exact dated original planet PBF URL, source byte count/hash, original database clock, full-planet coverage, ODbL and an independently reviewed native import-proof hash. The file's raw identity is checked before/after each query and must match the interpreter's original `timestamp_osm_base`. Original IDs/geometry remain intact. A full database admission is distinct from completeness of one bounded selection: overflow sentinels stay partial and cannot qualify an obstacle inventory or seamark tile. A database clock over 45 days old, future by more than 5 minutes, missing or changed is refused.

Caches preserve the **original database date**, not HTTP/Pi receipt time. Newly qualified caches have disjoint keys. Pi v5/v6 caches remain available only through the existing explicit stale-data option and retain their own dates; they cannot become new qualified fresh cache. Source expiry, streamed/declaration byte overflow, invalid UTF8, partial remarks and ignored native aborts are covered by actual transport fixtures. No success is fabricated on failure. No source positions, private credentials or raw diagnostic exceptions are logged by the new transport/gateway.

## Rights and honest availability

OSM remains community mapping and can be incomplete even when the database import and bounded query are complete. Its land/water shapes do not establish surveyed depth, tide datum or chart authority. Existing OpenStreetMap/ODbL attribution in Obs credits stays intact; generated/database derivatives must retain the original source facts and comply with share-alike. No public-mirror fallback remains in either actual shell CSP.

Primary source checks (17 October 2026): the [Overpass author's installation manual](https://dev.overpass-api.de/overpass-doc/en/more_info/setup.html) recommends 500 GB–1 TB storage and distinguishes base data from editor metadata/attic history. Its 350–400 GB base-data figure is explicitly dated 2023, not a current capacity measurement. The [OSM installation reference](https://wiki.openstreetmap.org/wiki/Overpass_API/Installation) identifies the author manual as primary and explains that PBF needs conversion for native import. The [ODbL 1.0 text](https://opendatacommons.org/licenses/odbl/1-0/) is the governing licence.

Reserve an independently provisioned filesystem with at least 1 TiB **available for the active base DB**, plus separate measured raw/import/rollback headroom. This is a proposed minimum reservation, not a claim wx has it or a guarantee of fit. Abort rather than consume another workload's reserve. No editor metadata, attic or area-generation daemon is needed by these seven recipes.

The next native proof must import a tiny fictional extract first under explicit memory/no-swap/disk/process limits, prove all seven actual recipes, empty versus incomplete output, original clock/ID/geometry, sentinel behavior, same-cohort retirement, query process cancellation and one-slot enforcement. It must then measure full-planet import/serving resources separately before creating the readiness file. The current world-facilities 2 GiB extraction envelope is not silently reused or increased. The full database and its private serving ingress are genuine unadmitted prerequisites; no install/start controller is armed in this packet.

Monthly base refresh can be a later bounded one-shot with two independently identified cohorts and publish-last readiness; no schedule or mutable current-db promotion is included now. The readiness file must be retired before an in-place update, or an immutable cohort must be selected atomically. Query receipt clocks never renew source age.
