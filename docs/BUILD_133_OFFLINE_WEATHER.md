# Build 133-10: public weather kept aboard

The Pi now keeps at most six NOAA/NESDIS GMGSI infrared frames using the exact app request: the full global ±60° belt, 3072 × 1288 pixels. It never crops to a boat area, uses tile fragments or invents frame times. The app still performs its existing per-frame tropical histogram anchoring and GPU colour treatment. Frames arrive as data URLs over paired, pinned boat-LAN transport. Satellite Mode permits those cached bytes but never falls back to a WAN capabilities or image request after a local miss. Existing frame age labels remain tied to the observation time.

The same store keeps public official analysis images by the build-133 registry IDs. The lazy analysis sheet tries its saved phone copy and the boat cache before a remote download. Image signatures, MIME, byte counts, source IDs and cache limits are checked. A chart retains its actual acquisition time; this is not an inferred issue or validity time.

Marine text covers selected NOAA high-seas products and two south Florida coastal zones. Original text is preserved. The WMO UTC header is checked against the product's printed full calendar date and the current clock before caching; an old February file cannot become an October forecast merely because its day of month is similar. The lazy Marine bulletins sheet filters product IDs for the selected region, names the source, shows issue and received times/ages, and links to the exact official product. Cached US text does not appear for an Australian point. Australia, New Zealand and other permission-held services remain official-site links, with no claim of worldwide cached coverage.

All `/api/offline-weather/*` GET handlers are cache-only, behind the existing app/device gate. They do not trigger an upstream request. The scheduler downloads only while its supplied boat internet-policy callback permits it, rechecking that policy before every asset and during response reads. An absent callback denies prefetching. Bounds are six satellite frames at 1 MB each, analysis assets at 2 MiB each for fixed registry IDs, and marine text at 100 KB per product. Fixed cache keys replace prior generations; retention is seven days with the existing cache expiry/purge mechanism. A failed refresh preserves the previous copy and its timestamp.

The app/Pi satellite request helpers, chart registry and marine source registry are mirrored with `node pi-cache/scripts/sync-offline-weather-sources.mjs`. Its `--check` mode verifies the source hashes and exact generated bytes. No licensed chart cells enter this store. The unused GIBS prefetch, RSS-as-JSON buoy prefetch, unused `/api/misc/buoys` handlers and unused tide station/NOAA/sea-level handlers were removed. The live `/api/tides/predictions` route used by WorldTides remains.

## Evidence and remaining gates

- Local: 67 satellite-layer tests passed, including the existing palette/anchor/lifecycle regressions and a cached Pi frame in Satellite Mode with zero WAN requests.
- Local: 29 service, marine-sheet and network-policy tests passed, including pairing changes, malformed snapshots, local misses and rejection of US coverage at an Australian point.
- Local: eleven Pi offline-weather/scheduler tests passed; complete Pi TypeScript checking passed. These tests use an in-memory cache. Native SQLite integration remains a Linux CI gate.
- Local: the command-lock route inventory passed after the new routes and dead-route removal. The full command-lock fixture suite passed 22 of 24 tests on Windows; the two failures compare POSIX file permissions (Windows reported decimal 438 / octal 0666 instead of decimal 384 / octal 0600). Those Linux security assertions remain unchanged and must pass in Linux CI. No safety denial was changed by this package.
- Live public reads on 16 October: NOAA GMGSI advertised five hourly frames, with a 42,730-byte capabilities document. The seven configured NOAA raw text URLs returned 200 and plain text. The South Pacific legacy raw file was stale from February and was excluded from the configured source registry. No production installation, remote publication or delivered-phone check occurred.

The full combined app/Pi checks, source-mirror gates, unchanged JavaScript budget, staged install/rollback/checksums, pi5 dry run, boat in-memory chart reread and safe physical Pi installation remain release requirements. Install only outside an anchor watch. The Pi track-upload DB/relay approvals and deployment remain separately held; this cache does not activate them.
