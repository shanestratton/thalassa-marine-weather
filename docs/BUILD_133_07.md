# Build 133-07 — navaids and chart sounding datum

This branch implements the confirmed 14 October package against foundation `6d5701e743c2d1828e8b14503acb381956f16e80`.

Schema 3 extracts LITFLT, LITVES, BOYINB, MORFAC, FOGSIG, TOPMAR and DAYMAR. Their symbol layers, tap popups, merge collections, render ordering and S-52 Standard display protection follow the existing registry. Line/area mooring facilities draw their charted outline; CATMOR 7 alone uses the mooring-buoy symbol. Unsupported or missing topmark shapes show an unknown mark. No lateral hand or cardinal quadrant is inferred.

The `.000` converter retains DSPM SDAT and VDAT separately; the SENC path retains the raw sounding-datum header. M_SDAT is always present as an explicit empty collection when none is charted. Partial/unreadable extraction omits it, so the app cannot mistake an incomplete local datum list for a complete one. VDAT and M_VDAT describe heights/clearances and never substitute for sounding datum.

Datum proof reads existing cell blobs only and remains in memory. Every relevant schema-3 cell and every local sounding-datum override must agree. Unknown, approximate, epoch-qualified and mixed datums refuse tide credit. The current WorldTides curve is explicitly LAT: MLLW, LLWLT and MSL charts retain charted depths until a prediction on the exact same datum is available. No conversion or relabelling is performed. Viewport changes clear the previous paint offset immediately; route chips and the departure sweep prove all their charted shallow gates. Tide cache hits and requests completing after a chart change are also guarded.

The inherited source contains no verified producer-datum allowlist, despite the older roadmap narrative. `VERIFIED_PRODUCER_DATUMS` is deliberately empty. AU/NZ country prefixes do not prove uniform LAT; an explicit unknown cell never falls through to a producer default. Adding a producer requires a source proving that its cells cannot mix datums.

References: [IHO S-57 UOC edition 4.4, sections 2.1.2–2.1.3](https://iho.int/uploads/user/pubs/standards/s-57/S-57%20Appendix%20B.1%20Annex%20A_Ed%204.4.0_FINAL.pdf), [IHO S-57 attributes TOPSHP/CATMOR/VERDAT](https://iho.int/uploads/user/pubs/standards/s-57/31ApAch2.pdf).

Registry tests cover icons/order/Standard display protection. Added tide-service tests cover datum changes before cache hits and while an upstream request is pending, plus whole-route bounds. Existing full-span tide and declutter tests are retained with schema-3 fixtures updated.
