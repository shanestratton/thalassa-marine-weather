# Retained original chart areas at offshore final emission

`readRetainedPassageChartAreas` borrows only current original chart data already held in RAM. It starts no disk, Pi, cloud or WAN read, performs no download or cache-LRU refresh, and does not acquire additional charts for a passage. It shares the actual 139-05 `readRetainedCellGeoJSONBytes` object-identity/byte receipt and genuine signed `readPiChartReadEvidence` authority. Metadata byte sizes, advisory indexes, chart-search names and cell bounding boxes cannot establish safety authority.

## Source and memory ownership

A request selects at most 14 navigation cells. The aggregate actual cache-accounted/active-owner original size is at most 16 MiB. Non-package originals remain WeakRef identity proofs, rather than a new pin on evicted whole blobs. Replacements, eviction, account A/B/A, registry version, revision/update changes and Pi permission/read-evidence expiry retire the proof. NOAA consent is read before using public sources and confirmed again as the final awaited phase, immediately before the exact audits and synchronous final callbacks.

`noaaPackageWindow` registers a bounded receipt only after its genuine verified local part reads and existing resident reservation finish. `noaaRetainedWindow` can borrow an already-active owner window that completely contains the original requested window; it adds no reservation or read and cannot extend that owner. Owner release removes the receipt and clears its raw blob reference immediately. Borrowers then expose no raw blob and become invalid. An undersized, retired, changed or absent owner stays unavailable. At most 64 active receipts are indexed; exceeding that bound simply leaves the additional view unavailable to retained readers. Unrelated windows do not retire a passage proof merely by opening or closing.

Selected fields have one separate **4 MiB aggregate allowance across all active readers**. It never evicts unrelated map/chart RAM. The reader strips names/labels and all properties except original RESTRN/ORIENT, measures each selected record before retaining it, and compiles bounded complete original polygons. It retains no full original blob across awaits. Budget exhaustion yields an explicitly unknown field, never a truncated positive proof. Selected reservation release is idempotent and clears its geometry. Original data is not mutated, clipped, persisted or exported.

## Validator and consumer lifetime

The passage validator holds its actual private-policy lease across every async depth/tide/detour/caution/hazard phase, with an initial installed-chart metadata/content-identity fence checked through every await. Once the staged core finishes its normal cache warming and final geometry work, it acquires this retained original-chart lease over the immutable ORIGINAL window. Benign same-content RAM warming is then usable; changed metadata/content cannot be silently recaptured as a new depth/source generation. The original-chart lease spans publisher loading and the final permission confirmation through exact audits, callbacks and return. Acquired-but-not-yet-assigned and late-reader cleanup use the same local idempotent disposer. The final permission confirmation is the last await. Exact private and original-chart finished-geometry audits, current-source checks, result-local callbacks and singleton publication then run synchronously before geometry is returned.

`onRouteAreaCaveats(notes, sourceCurrent?)` optionally carries an in-memory weak current-source function. It remains meaningful after the geometry leases release: it checks current private context plus auth/registry/object/Pi receipt/NOAA owner authority, holding no geometry or selected reservation. Exceptions become false. Enhancer, constrained passage and berth consumers recheck it at awaited return and final adoption; it is never persisted or exported. Planner/model-selection adoption wiring is owned by the separate planner packet.

Unsupported unsplit dateline geometry, overlarge windows/cohorts, absent retained charts and missing original geographic coverage remain explicit unknown/unavailable, with no hidden acquisition or invented authority. These limits are normal retained-only behavior and must not be described as universal offshore rule coverage.
