# Inert bundled UI data and bounded proof

The configured application build explicitly supplies one `inertUiData` registry to the unchanged class/UI/SVG selectors. Their exact existing packed tuples become genuine `application/json` blocks in each reachable HTML graph; generated virtual modules synchronously consume those blocks through `readPackedUiData` and the unchanged `decodeClassNames`. Expected content-derived identity, encoded length, inflated byte count, row count and checksum are compiled independently of the HTML. No eval, remote fetch, async bootstrap, application globals, feature/target/minifier/CSP/budget change or encoded-data fallback is used by the configured application. Standalone helper builds must opt in explicitly.

The post HTML hook examines actual static and dynamic output-chunk imports/modules. Blocks are placed at body-prepend after charset/CSP; async module entries, duplicate preexisting data, unsupported JS/non-document roots and worker DOM-reader imports refuse. Every table is bounded before parsing and decoded by the original checksum/header/shape/output guards. Its node is removed synchronously without a permanent encoded-data cache. Table IDs include owner and pool index, preserving independent consumption even when two tuples contain the same bytes. HTML block order is deterministic independently of load scheduling.

Missing, stale, duplicate, malformed or corrupt data produces a bounded fixed-text alert with an explicit 44-pixel Reload button independently of React and main/Logs entry handlers. The fallback never erases an already-running application or auto-reloads. A static dependency failure stops its importing entry body/provider mounting; no claim is made that arbitrary sibling module initialization is isolated.

The existing service-worker navigation semantics stay unchanged. Each cached deep-navigation HTML URL carries another copy of its required inert payload, so runtime SW storage amplification remains an explicit cost. Native `dist` remains self-contained; no network data source is introduced.

The final focused regression run passes **99 cases across 10 suites**: real multi-entry minified Vite fixtures; exact tuple/vocabulary reconstruction and all four independent UI pools through inert HTML; immediate data readers; missing/duplicate/stale/malformed/header/metadata/raw-size refusal; fixed fallback/retained app/no-fetch behavior; actual unsupported JS/async/worker guards; existing class/UI/SVG semantic and decoder bounds; actual route-job purity/lazy boundaries; worker Sentry guards; and existing CSP guards. Receipt: `work/validation139-inert-proof-focused-final.log`. Only small synthetic fixture builds were run by this agent.

The earlier `WorkerSentryNoop` failure was repaired separately in `1f6e91303`: its regex mistook erased `ImportTypeNode` expressions for runtime imports, producing a false 450-module app graph instead of the actual 76-module runtime closure. It now reuses the build's existing TypeScript AST collector, with real static/re-export/dynamic/computed-import controls and negative inline/declared/named/exported type-import controls. Every original logger/Sentry assertion and injected-negative assertion remains and passes; no source allowlisting or app dependency change was made. ## Offline scope and repeatability

The actual SW deliberately bypasses `localhost` and `127.0.0.1`. Proof therefore uses the second secure loopback origin `127.0.0.2` and the unchanged actual SW. Chrome additionally passed `context.setOffline(true)` in the focused original proof. Windows WebKit aborts even a cached SW navigation under that emulation flag, so the shared final proof severs server transport instead: its network-first fetch actually fails, cached HTML/chunks must supply the page, and failed transport requests are counted. Mini proof also exercises a new offline deep path falling back to cached Index. This is a controlled transport outage, not physical airplane-mode/device acceptance. SW retention policy is not broadened.

Run `npx playwright test --config=playwright.inert-ui-data139.config.ts` for the synthetic matrix and `npx playwright test --config=playwright.inert-ui-artifact139.config.ts` for the explicit retained actual artifact. Windows proof used installed Chrome (`channel: chrome`) and the existing `PLAYWRIGHT_BROWSERS_PATH=.../work/browser-runtime133`; no browser download occurred. The proof servers use isolated ports 4307 and 4309 and create dedicated temporary sibling folders; they make no provider/backend calls or native changes.
