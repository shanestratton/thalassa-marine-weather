# 139-04 composite field and engine integration

`services/engine/exclusionField.ts` compiles original RESARE entry restrictions (7/8), TSEZNE polygons, explicitly supplied manual no-go polygons and indicative marine-park caution areas into an independent RAM-only geometry snapshot. It copies no chart names or cell identifiers. Anchoring/fishing/no-wake restrictions are not reinterpreted as transit prohibitions. Hard separation-zone avoidance is a conservative planning policy, not a claim that every real-world crossing is legally prohibited.

The shared WGS84/topology validator bounds selected geometry to 2,000 features / 50,000 vertices / 4 MiB with a two-million-comparison topology ceiling; source scanning is separately capped at 16,000 objects. Malformed, unsplit dateline and non-polygon hard constraints refuse the review rather than disappearing. Missing chart-class coverage still needs to be disclosed by the caller.

Rasterization produces private masks without changing chart grids, depths or preference flags. It includes polygon interiors, holes, tiny islands, boundary supercovers and both sides of exact grid-edge/corner contacts. Boundary segments are clipped before walking the selected grid. The 2.5-million-cell and eight-million-operation ceilings are fixed. Park caution never becomes a hard transit prohibition.

The engine now compiles a fresh field from its actual input layers, ignoring caller-supplied compiled fields. `applyExclusionField` creates the route-private grid before endpoint/component rescues. Hard masks remain authoritative in endpoint carving, component bridging, navigability, A* and smoothing; indicative park cost is shared by A* and smoothing. Every completed engine polyline is checked against the original geometry after its final lead/tail/refinement splices. Existing no-restriction results are preserved apart from measured phase timings.

The focused module, real-engine detour and existing regression checks pass 32 cases. The first invariance test compared wall-clock/cache timing fields and failed on those fields only; it now compares all result fields except those measurements. This is a source integration checkpoint: actual application source collection, missing-class disclosure, manual controls, TSS lane guidance and current verified park borrowing are still under construction. No release, backend activation or Pi installation is claimed.

The separate final-line audit checks complete segments against original polygon geometry after all route splices. It detects narrow crossings between route vertices and exact boundary contact. Grid masks and sampled route points are insufficient proof on their own. The complete audit has its own geometry/operation limits and refuses unsupported route geometry.

The application now collects original RESARE/TSEZNE collections from its held chart cohort. An absent class stays unknown; it is not interpreted as an extracted empty collection. The worker audits the actual post-shadow result and the main thread repeats the audit against its held original layers before returning it. Intersected missing-class coverage produces a persistent number-free caveat in the passage planner, tracer, Auto proposal and saved route. Cloud hints cannot bypass the final audit.

The inshore application path now reads the actual private/retained-park lease before preparing its job. Its source window covers both the complete engine padding and lead-overlay envelope; a final line outside that read window is held for a new read. The dedupe key and every source/worker wait bind the private-policy generation. A corrupt hard policy or expired/changed lease returns an explicit exclusion-unavailable failure, and the lease is released after the actual computation ends. Caller fallback handling and passage-wide/offshore final enforcement are still being integrated; this checkpoint is not the complete 139-04 release.

Thirty-eight focused source/window/join cases pass, including a corrupt read with zero route jobs, a private edit starting a distinct run and rejecting its predecessor's late line, expiry without a key event, and eventual lease release. Existing synthetic scenes explicitly declare that they contain no private files or park source. The cancellation fixture holds a real cell wait to preserve its original stop window across the new asynchronous source read; its work-after-stop assertions are unchanged. Initial fixture placement/hoist and floating-point comparison failures remain in their logs. Whole-application compile and composed release checks are pending.

Parent integration checks pass 63 focused cases and a separate 36-case prep/clone/purity run. The original prep goldens correctly failed after restriction inputs and missing-class metadata were introduced. Four synthetic goldens were updated, then passed without write mode across all 16 completion orders: their route summaries and geometry are unchanged; the provider has one additional restriction-check warning (11 to 12). The first failed logs are preserved. An incomplete private-track mock is now explicit rather than triggering a caught missing Supabase export. Engine closure purity remains strict: the shared final audit lives in the mirrored pure engine module, with no new IO allowance.

Seventeen focused cases pass, including thin polygons, source-copy independence, holes, exact boundaries, tiny islands, stale callbacks, malformed topology, bounded grids and unchanged chart arrays. The module is not yet called by the application. Remaining work is per-request grid/cost integration, refusal/final-service guards, explicit manual no-go controls and lifecycle fencing, traffic-lane guidance and verified marine-park data wiring. No compiler, configured size or live routing behavior is claimed for this foundation.
