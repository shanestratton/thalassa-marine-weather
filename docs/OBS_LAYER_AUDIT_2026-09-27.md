# OBS layer audit — 27 September 2026

Scope: code/lifecycle/legend audit of the current local branch. No live-provider validation or deployment was performed by this audit. “Off” below means a fresh OBS mount; normal tab navigation retains the mounted map's deliberate choices. MapHub passes `startEmpty=true` to weather state; browse toggles and ENC also start off. Ownship and armed safety overlays are separate from optional browse layers.

## Integrated result

- Live / Sea / Sky / Routes menus now sit above chart overlays inside an isolated map stacking context. App dialogs and alarms retain priority. The helm FAB has a real 44px minimum target on small phones.
- A single collapsible **Layer key** covers active weather, ENC, AIS, lightning, squalls, storms, tides, moorings/anchorages, routes/tracks and protected areas. Inspect is a tool, not a separately coloured layer. ENC vocabulary is reused from the existing chart key, rather than inventing a second palette. Provider credits remain visible while the key is collapsed; the detailed squall explanation remains available in the big information panel too.
- Weather tabs select the dataset to control, without silently changing unrelated clocks. Combined layers retain their individual scales/units, model selector and selected-frame timestamps. Passage look-ahead owns its scrubber; the layer key remains available without a competing timeline.
- Follow-up decluttering: chart weather controls fold after six idle seconds into a two-line, tappable status pill. Selected layer/model, playback and actual valid UTC remain visible; unavailable/stale data stays flagged. Playback continues independently. Held scrubs, keyboard focus and native pickers prevent automatic folding; backgrounding pauses the idle timer. Embedded controls are unchanged.
- Pressure refreshes on browser/native resume and at its refresh interval, rejects expired/future or older replacement data, and no longer clamps wind playback beyond coverage onto the final pressure frame. Saved data, model age, valid UTC and out-of-coverage states are explicit. Movement hints now represent 12 actual hours, not 12 possibly two-hour frames.
- Squall snapshot age is independent of download time. Tile loading/failure is reported; unknown provider clocks remain unknown. This is a heavy-rain proxy, not a gust measurement.
- AIS legend colours now use the renderer's shared palette. Clear All clears routes/tracks without opening their pickers. Tide search status is displayed, its zoom threshold is explained, and stationary station searches refresh after five minutes.

The inventory below records discovery-time baselines as well as fixes. References to baseline missing keys or root integration are superseded by the integrated result above.

### Data limits retained, not concealed

- Primary pressure comes from the existing GFS backend, which conservatively waits five hours after each six-hour cycle. Its +42h source horizon yields roughly 31–37h of future coverage at download; it is not five days of pressure. The Open-Meteo fallback does not expose a trustworthy model-run time. No backend/provider deployment was made.
- OpenWeather static tiles expose neither a reliable frame timestamp nor tile availability to the current controls. CMEMS exposes selected-step readiness but not valid UTC. The key states those limitations instead of saying “Live.”
- Storm-catalogue errors can still return cached/empty results; an empty chart is not an all-clear. The new storm key says so. Regional anchorage-tile error reporting remains less complete than worldwide-reference reporting.
- Local fixture checks do not establish current live-feed coverage, hydrographic currency, or navigational safety. Physical-iPhone/on-water and provider-network smoke checks remain appropriate before release.

## Findings and residual limitations

1. **Cyclone invented forecast — fixed:** removed the service's 72-hour straight-line extrapolation from two historical fixes. Missing official coverage stays empty; observed history/current positions and actual provider forecast points are preserved. The accompanying hook fix removes an old sleeve when a new result has no forecast. Parser fixtures cover both sides of this boundary. A successful HTTP response still does not establish provider freshness or official probability-envelope provenance.
2. **AIS ownship-floor resume — fixed:** scheduling now runs in `finally`, so Satellite mode pauses requests without ending the 90-second lifecycle. The policy-on→off test keeps AIS enabled throughout, proves the ownship fetch resumes, and proves unmount stops subsequent calls.
3. **Error versus empty:** storm fetch failures fall back to cached catalogue or `[]`; the visible storm hook has no load/error state. Tide search state was discarded at the MapHub call; root is addressing it. Regional anchorage tile failure logs but does not amend the worldwide-reference status.
4. **Native/full-style restoration:** current base choices do not invoke `map.setStyle()`. Lightning and cyclone canvas overlays have no general style-replacement restoration listener; do not claim that hypothetical path passed merely because mount-order tests pass. Tide, cruising references, routes and the updated offline fallback have explicit restoration coverage.
5. **Menu versus popups/modals — fixed and browser-verified:** the menu's 10020 band clears chart popups (10000), tracer cards (9995), and storm cards (760). The outer `map-hub` isolation boundary keeps those chart-local numbers below ordinary body-portalled app modals (1100). Chromium and WebKit verify category/item clicks, closing, both app/chart modal paths, and minimum 44px helm/MOB controls. The fixture reduces spring motion; it does not claim full animation timing coverage.
