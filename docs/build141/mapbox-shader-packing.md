# Pinned main-renderer shader representation

The production plugin changes only89 exact GLSL literal representations in the reviewed Mapbox GL JS3.19.0 distribution (SHA-256 `07cd585ebf678c90e00e70c5d02b0ea7c8c2d76df6dc8e599ddc4de0ffe5f9b4`). Unknown SDK bytes, callback layout, shader inventory or pool count fail closed for fresh review. Original legal notices and every nonliteral SDK byte, including billing, telemetry and public APIs, remain unchanged. Reversing the prelude/literal substitutions reproduces the entire original SDK source exactly.

All selected literals belong to the third/main renderer callback. The first/shared and second/worker callbacks are serialized by Mapbox's existing runtime; both retain byte-identical input source and acquire no external decoder reference. A static CommonJS require connects the normal main build to a pure virtual counted-JavaScript table. Development, raw/URL assets and independent worker builds retain their original path. Vite/CommonJS performs ordinary dependency analysis and hashes the final modules; no hashed output is rewritten.

The unchanged bounded decoder reconstructs two pools (119/20 chunks, raw127,508/28,176 bytes). Each source string is split into at most2,048-character rows, then joined exactly. No shader whitespace/precision/type is changed. The scratch rows live inside an initialization function and can retire after the immutable89-string result is created. Decode occurs once through normal module caching, never per frame. Existing encoded/raw/count/word/output ceilings remain unchanged; no DOM reader, eval, new package or raised cap is introduced.

The isolated actual minified production SDK pair is1,683,906 bytes original versus1,567,129 packed:116,777 bytes recovered including the table and decoder. This is a complete isolated graph, not a claim about final combined app bytes. Root must still run the exact configured build and unchanged JavaScript/asset/worker gates.

The original strict final worker-Blob byte comparison failed and remains preserved. Whole-graph Terser changes lexical identifier allocation even when input callback bytes are unchanged. The approved independent proof parses both actual final worker Blobs with Acorn and resolves bindings using ESLint scope analysis. It permits resolved lexical renames only; property keys, literal values, free/global names, capture targets and executable/control order stay exact. Fourteen controls cover nested/shadowed/catch/class/label bindings and reject property/global/free-name/capture/literal/operator/order, tagged raw-template, regex/private-property and dynamic-scope changes. This is independent from Terser and never executes reconstructed source.

The first Chrome production pair rendered identical compiled shader sources and18,803 actual red pixels, with working Blob workers and unchanged public exports. Final Blob bytes differ, while canonical AST hashes match across19,421 bindings (4,208 renamed). The original strict-failure trace, all WebKit baseline failures and the subsequent app-context fixture comparison are retained in external proof. The fixture aborts provider traffic but permits only its exact local HTTP/Blob origin under the unchanged strict self/blob CSP.
