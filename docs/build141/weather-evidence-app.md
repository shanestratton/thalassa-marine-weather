# Issued station evidence in the model picker

The picker contains a lazy, explicitly opened skill panel within its existing
scroll area. Coordinates select the closest current published station within
50 nautical miles locally; no location or account data is sent to the publisher.
No station in this bounded catalogue is a partial-coverage result. A nearby
warming station is named without MAE, winner or automatic model selection.

Scores are separate by wind speed/wave height and original forecast lead. The
client repeats the server's two-week, effective-N30, ten-day span and comparable
model-pair gates. Exact source IDs remain distinct: own-server IFS0.25° skill
does not score the picker’s IFS9km, a blend, a different provider or motion seas.
NOAA observations retain preliminary automated realtime screening labels.

The reader is import-inert. Explicit caller-owned sessions fetch only fixed
public paths, omit credentials, refuse redirects and verify the exact original
index/detail lengths and SHA256. Pointer, index, detail and cumulative session
limits are1024B,256KiB,128KiB and2MiB. No global/durable cache exists; a session
keeps at most two leaf details for at most15minutes and respects original
pointer/station expiry. Abort, owner retirement, A/B/A reads, ignored native
fetch, stalled streams and late response-body cleanup are bounded. Closing the
panel retires its session. Expiry never initiates a background refresh.

Buoy cohort availability accepts up to90minutes after construction, matching the
reviewed weather13e0 source. Each station independently retains its original
observation-plus-three-hour/rights ceiling. Old one-hour pointers remain valid
under their original clocks; no fixture or deployed generation is rewritten.

The original fixture bytes are actual collection-only candidates from wx,
kept separately from independent public-copy deployment proof. They contain
29public institutional buoy stations and20warming skill stations. They contain
no yacht/user coordinates, secrets, fabricated scored history or live account.

interaction suites;45existing picker/status cases. Browser geometry/appearance,
