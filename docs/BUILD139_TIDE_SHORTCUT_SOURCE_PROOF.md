This packet adds a default-off, fixed-speed, exact-clock tide shortcut preview to the existing short, direct passage flow. It does not qualify today's tide sources for navigation, change departure or add a wait automatically. WorldTides remains informational: the user has no verified navigation permission. The current aboard adapters return no original navigation sample series, and the independent reviewed navigation-rights/datum-tie registry remains empty. ## Concrete implementation

- The control stays inside the existing scroll-capped PassageBanner. It defaults off, takes a 1–60 minute arrival buffer, displays source/clock limitations and has no wait/departure action. Long and via passages retain the existing berth routing behavior.
- A fresh strict grid is built from the actual original chart cohort. The optional time-labelled search never carves or snaps, opens unknown/drying/land/physical/restricted cells, writes shared depth, changes the existing default path, or treats a loop as a holding wait. The strict baseline and proposed shortcut share the same input grid; a shortcut must actually require qualifying tide and save at least 20 m.
- Original sounding/depth-area numeric minima only lower depth. Full-cell original positive DEPARE coverage, actual CATZOC, original hazard/land/overhead footprints, source clocks, complete requested class set and full padded source-window bounds are independently checked again on the final exact path. Diagonal flanks are included. An exact original-area union cannot fill a hole or gap; original drying overlap is subtracted. A 60 m original-physical-footprint margin remains conservative. Bridges do not become clear from a sounding-datum tide.
- The boolean operations reuse the existing pre-allocation Martinez work ceiling, with 32 original polygons, 512 input/output vertices and a cumulative work cap. There is no hull, sampling or geometry fallback. Final footprint proof is limited to 4,096 distinct cells, 262,144 visited vertices and 500,000 comparisons; over-cap means held. The pure search caps its grid at 2.5 million cells and labels at 25,000, with bounded source/final review and search deadlines.
- Public package geometry uses the existing complete cohort lease. A protected Pi view requires a process-local read receipt minted only after the real verified download and successful import, plus its exact already-decoded retained RAM object and measured cache byte count. It does not decode another private blob or contact Pi/disk/WAN for routing. Complete source membership is capped at 14 cells and aggregate retained geometry at 16 MiB. Missing, unmeasured, expired or evicted members hold the result. Transport proof is separate from chart availability, rights and datum proof.
- Source receipts bind owner generation, active vessel, pairing revision, cell content and private-vault clear revision; source permits additionally bind chart metadata and protected-memory generation. The real manual no-go/retained MPA accessor is leased through worker completion and final audit. A failed hard private policy cannot become an empty exclusion field or offshore fallback.
- Exact coordinates, grid identity, unique adjacent indices, unrounded per-node clocks/distance and original interval minima are reread before display. Independent pre-await snapshots reject in-place aliases. One private, expiring RAM preview retains these leases while needed and retires on actual context changes. It is marked unverified; save, export, use-as-route and watch actions remain held. Serialized or spread copies cannot finalize a preview or mint a permit.
