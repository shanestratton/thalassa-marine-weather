Thalassa

Voyage Log API

A read-only JSON API for a single vessel's published voyage log — diary entries, GPS track, and the latest telemetry. The public page at https://<handle>.thalassawx.app is built on this exact API; you can build your own front-end against it however you like.

Endpoint

GET  https://<your-project>.supabase.co/functions/v1/voyage-log?handle=<handle>

This endpoint is intentionally public and does not use an API key. Anyone who knows or guesses an enabled public handle can read the published feed. The skipper controls the page from Thalassa and can unpublish individual diary entries or switch off the entire Voyage Log.

Query parameters

Param Description
handle The vessel's public handle — a slug chosen for its public voyage page, e.g. demo-vessel.
trip Optional. Omit it for the full configured feed, use latest for the current or most recent passage, or pass a trip catalogue id returned by the API.

Response

200 OK with a JSON body. Cache-Control: public, max-age=60 — the underlying data only moves every few minutes, so caching for a minute is plenty. CORS is open (Access-Control-Allow-Origin: *), so you can call it directly from any browser front-end.

Fields

Field Notes
vessel Vessel identity. model may be null.
entries Published diary entries, newest first (max 200). Only entries the skipper explicitly published appear here — the private diary is never exposed. latitude/longitude may be null if the entry has no pin.
track GPS breadcrumb for the configured window (default 30 days), oldest first. Numeric fields may be null for older fixes.
telemetry The most recent track point, surfaced for a "live" ribbon. null if the vessel has no track yet.

Errors

Errors return a JSON body of the shape { "error": "…" } with one of:

Status Meaning
400 handle is missing or invalid.
403 The vessel exists but its voyage log is switched off.
404 No vessel with that handle.

Example

const res = await fetch(
  'https://your-project.supabase.co/functions/v1/voyage-log' +
  '?handle=demo-vessel&trip=latest'
);
if (!res.ok) throw new Error((await res.json()).error);
const log = await res.json();

console.log(`${log.vessel.name} — ${log.entries.length} entries`);
if (log.telemetry) {
  console.log(`Now: ${log.telemetry.sog} kt, baro ${log.telemetry.baro} hPa`);
}
Building something with this? It's the same data the official renderer uses — feel free to lay it out however suits you. Treat every returned field as public. The skipper controls what's published and can switch the whole log off at any time.
