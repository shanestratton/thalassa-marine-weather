## Decision (our recommendation)

1. `stopDetail()` returns structured fields: `{ title, sub, level, reason,
   why, route, timeline: Leg[], facts: Fact[], notes: string[], leave:
   LeaveChip[], footnote: { short, full } }`. Every string the old rows carried
   is still produced (in facts, notes, footnote.full or Sources), so nothing
   true is lost; tests move from string rows to fields.
2. The fallback branch in TodayStopDetail (no weather) uses the same structure
   with empty timeline and the reason; no second copy of prose.
3. "Leaving a marina: check its approach depth…" moves into `footnote.full`
   and Sources once, and shows on the page only when the route was NOT routed
   (127-PYD-11 already hides it on a routed stop, where its leave row says
   when the tide allows the approach).
4. Leave chips carry `homeMs` (or `arriveMs` overnight) from
   `plan.departures`; "dusk" when within LIGHT_MARGIN of last light.
5. ✕ is the only close; focus returns to the row that opened it.
6. Notes chip opens a nested list (`TodayModal`, centred) with the reviewer's
   words whole.
